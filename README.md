# RealKeyword AI News

최근 24시간의 AI 뉴스와 유튜브 영상을 한눈에 모아 보여주는 Windows 트레이 앱입니다.

## 주요 기능
- 공식 AI 개발사(OpenAI·Google DeepMind·Anthropic·NVIDIA) 등 AI 뉴스·블로그·유튜브를 자동 수집
- 구글 로그인 시 내 유튜브 구독 채널의 최신 영상도 함께 표시
- 영상 자막 기반 한국어 요약(엑기스)
- 기사·영상 카드별 AI 요약 및 질문

## 다운로드
[최신 릴리스](https://github.com/chdnl0420-svg/RealKeyword-releases/releases/latest)에서 `RealKeyword-AI-News-Setup-x.y.z.exe` 를 받아 설치하세요. 설치 후 자동 업데이트됩니다.

## 개인정보처리방침
구글 로그인 / 유튜브 구독 기능 관련: [개인정보처리방침](https://chdnl0420-svg.github.io/RealKeyword-releases/privacy.html)

## 데이터 처리
구글 로그인으로 가져온 유튜브 구독 목록과 로그인 토큰은 **사용자 기기에만** 저장되며(토큰은 OS 보안 저장소로 암호화), 외부 서버로 전송하지 않습니다.
